# aidd-bekarys

AI-Driven Development — 1-апта жобасы (Yklasuly Bekarys).

## Мақсаты

Жеке репозиторий: Git және GitHub жұмыс тәртібін қолдану —
тармақ → коммит → PR → merge.

## Іске қосу

```bash
python hello.py
```

Скрипт ат сұрап, мынадай жауап береді:

```
Атыңызды жазыңыз: Әли
Сәлем, Әли! Бүгін 06.11.2026
```

## Құрылымы

- `hello.py` — сәлемдесу скрипті (стандартты кітапхана ғана)
- `.gitignore` — репозиторийге жүктелмейтін файлдар (.env, .venv/, ...)
- `.env.example` — орта мәндерінің үлгісі
- `docs/prompt-log.md` — AI агентке берілген промпттар журналы
